# Contributing

Thanks for your interest in contributing.

## Workflow

1. Create a feature branch from `main`.
2. Make focused commits using clear messages.
3. Run tests and checks locally.
4. Open a Pull Request with a concise description.
5. Keep changes small, documented and reviewable.

## Commit convention

Prefer Conventional Commit style:

- `feat:` new functionality
- `fix:` bug fix
- `docs:` documentation
- `refactor:` code restructuring
- `test:` tests
- `chore:` tooling or maintenance

## Security

Never commit passwords, API keys, service-account files, private keys or other secrets. Use environment variables and GitHub Actions Secrets where appropriate.
